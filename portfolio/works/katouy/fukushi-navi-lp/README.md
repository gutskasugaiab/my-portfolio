# 福祉のお仕事ナビゲーター LP

サービス管理責任者(サビ管)・児童発達支援管理責任者(児発管)の応募獲得を目的としたLPです。
応募フォームは「かんたん30秒 無料仕事診断」の診断形式になっています。

## フォルダ構成

```
fukushi-navi-lp/
├── index.html      … ページ構造(セクションごとにコメントで区切りあり)
├── css/
│   └── style.css   … デザイン(冒頭に目次と修正ルールあり)
├── js/
│   └── script.js   … 診断フォームの動き(冒頭に処理の全体像あり)
└── README.md       … このファイル
```

## 確認方法

`index.html` をブラウザで開くだけで動作します(ビルド不要)。
SP表示は Chrome の検証ツール(F12 → デバイスツールバー)で確認してください。

## デザインのルール

- 色・文字サイズ・余白はすべて `css/style.css` 冒頭の `:root`(デザイントークン)で定義しています。
  **変更するときはトークンを修正**してください。各所に直接カラーコードやpxを書かないこと。
- サイズは rem 基準。`html` の `font-size` を vw に連動させているため、
  画面幅に合わせてページ全体がなめらかに拡縮します(vwを書くのはこの1か所のみ)。
- ブレイクポイント:SP切替 `max-width: 860px` / 小さいSP `max-width: 480px`
- クラス名は「ブロック_要素」形式(例:`voice_card`、`q_title`)

## フォームの仕様

| STEP | 内容 | 動き |
|------|------|------|
| 1 | 希望職種(単一選択) | 選択肢を押すと自動で次へ |
| 2 | 叶えたいこと(複数選択・必須) | [次へ][戻る]ボタン |
| 3 | 興味のある施設(複数選択・必須) | [次へ][戻る]ボタン |
| 4 | 連絡先入力(全項目必須) | 入力チェックあり |
| 5 | サンクス表示 | 担当者連絡・自動返信メールの案内 |

必須項目:氏名/生年月日/保有資格/住所/電話番号/メールアドレス
