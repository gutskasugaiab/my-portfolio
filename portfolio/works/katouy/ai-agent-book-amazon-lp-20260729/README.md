# 全て丸投げAIエージェント！ — Amazon発売記念LP（制作サンプル）

架空書籍のAmazon誘導LP。静的サイトのため、ビルド・依存パッケージ・サーバーサイド処理はありません。

## ディレクトリ構成

```
.
├── index.html      エントリポイント。これをブラウザで開く
├── css/
│   └── site.css    全スタイル（単一ファイル）
├── js/
│   └── app.js      オープニング演出、スクロール連動、モーダル、シェア
├── assets/         写真8点（PNG）
├── demos/          スクロール演出の単体デモ（LP本体からは未参照）
├── docs/           制作ドキュメント（LPの動作には不要）
└── screenshots/    表示確認用（現在は空）
```

## 動作確認

`index.html` を直接ブラウザで開くと、ブラウザのセキュリティ制限（`file://`）で一部の挙動が変わる場合があります。ローカルサーバー経由での確認を推奨します。

```bash
python -m http.server 8000
```

上記を実行後、`http://localhost:8000` を開いてください。

## 各ファイルの役割

| パス | 内容 |
|---|---|
| `index.html` | 本文・構造。テキストはすべてHTML内に直書き（画像化していないため編集・検索が可能） |
| `css/site.css` | 配色、レイアウト、レスポンシブ、アニメーション |
| `js/app.js` | 外部ライブラリ不使用。`prefers-reduced-motion` 有効時は演出を無効化 |
| `docs/brief.md` | 要件・与件 |
| `docs/copy.md` | 原稿（コピーデッキ） |
| `docs/research.md` | 調査メモ |
| `docs/build-log.md` | 作業記録（英語） |

## 公開前に必要な作業

このLPはサンプルのため、以下が未確定のままです。
